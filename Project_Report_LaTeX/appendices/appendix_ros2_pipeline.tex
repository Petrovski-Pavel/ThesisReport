\chapter{ROS pipeline parameter reference}
\label{app:ros2_params}

This appendix summarizes the main runtime parameters of the deployed
\gls{ros} perception pipeline. The tables are intended as a practical reference
for reproducing experiments or adjusting node behavior during deployment. Values
shown in the ``Default / configured value'' column correspond to the final thesis
configuration where this was defined explicitly in the YAML files; otherwise the
node's declared software default is reported.

\section{Detailed runtime timing breakdown}
\label{app:ros2_pipeline_timing_detail}

For readers interested in more detailed node-level runtime information beyond
Table~\ref{tab:ros2_pipeline_timing}, Table~\ref{tab:app_live_runtime_breakdown}
reports the stage-level timing ranges measured for the final live-camera runtime
configuration with \glsentryshort{ocr} capped to four \glsentryshort{roi}s.

The stage labels in the table correspond to the following execution boundaries:
\begin{itemize}
    \item \textbf{\texttt{cv\_bridge}}: conversion from the incoming image message to an OpenCV image.
    \item \textbf{\texttt{pre}}: preprocessing before the \glsentryshort{tensorrt} engine call.
    \item \textbf{\texttt{infer}}: measured \glsentryshort{tensorrt} inference time.
    \item \textbf{\texttt{depth}}: the mask-guided depth and representative-center estimation block in the \glsentryshort{yolo} node.
    \item \textbf{\texttt{loop}}: the per-target processing loop in the \glsentryshort{yolo} node.
    \item \textbf{\texttt{post}}: postprocessing after network output decoding and before publication.
    \item \textbf{\texttt{publish}}: publication of the output message.
    \item \textbf{\texttt{total}}: complete node callback time for that processing cycle.
\end{itemize}
